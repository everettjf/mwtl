mwtl::Window<T>

Window is the WTL CRTP main top-level window base. It keeps HWND and message maps visible and places a noexcept C++ exception boundary around the real WTL WindowProc path.

Native message interoperability

constexpr UINT kRefresh = WM_APP + 1;

class MainWindow final : public mwtl::Window<MainWindow> {
public:
    void BuildUI() { SetTitle(L"Window demo"); }

    BEGIN_MSG_MAP(MainWindow)
        MESSAGE_HANDLER(WM_LBUTTONDOWN, OnClick)
        MESSAGE_HANDLER(kRefresh, OnRefresh)
        CHAIN_MSG_MAP(mwtl::Window<MainWindow>)
    END_MSG_MAP()

private:
    LRESULT OnClick(UINT, WPARAM, LPARAM, BOOL&) {
        return ::SendMessageW(GetHwnd(), kRefresh, 0, 0);
    }
    LRESULT OnRefresh(UINT, WPARAM, LPARAM, BOOL&) {
        SetTitle(L"Native message received");
        return 0;
    }
};

Key behavior

  • BuildUI() runs during WM_CREATE after the HWND is attached.
  • GetHwnd() returns a non-owning native handle; IsWindow() observes its current validity.
  • A derived message map must chain back to the exact mwtl/WTL base specialization with CHAIN_MSG_MAP.
  • The old HWND is no longer exposed after WM_NCDESTROY.
  • A creation-stage exception fails Create; a normal-message exception triggers safe shutdown; no exception crosses the Win32 ABI.
