Build guide

Build and run

Requirements: Windows 10 version 1809 or newer, Visual Studio 2022 or newer, MSVC, a Windows SDK, the C++ ATL component, CMake 3.21 or newer, and C++20.

x64 Debug

cmake -S . -B build/x64 -G "Visual Studio 17 2022" -A x64 \
  -DMWTL_BUILD_EXAMPLES=ON -DMWTL_BUILD_TESTS=ON
cmake --build build/x64 --config Debug --verbose
ctest --test-dir build/x64 -C Debug --output-on-failure

CI validates both x64 Debug and Release configurations. The public API remains C++20-only and uses concepts, ranges, std::source_location, and ref-qualified fluent builders.

Run component examples

build\x64\examples\application\Debug\mwtl_application_demo.exe
build\x64\examples\window\Debug\mwtl_window_demo.exe
build\x64\examples\hello\Debug\mwtl_hello.exe
The current supported architecture is x64. ARM64 is deferred until it has a maintained build and runtime validation environment.

Install and consume

cmake --install build/x64 --config Release --prefix C:/deps/mwtl

# consumer CMakeLists.txt
find_package(mwtl 0.4 CONFIG REQUIRED)
target_link_libraries(my_app PRIVATE mwtl::mwtl)

Configure the consumer with -DCMAKE_PREFIX_PATH=C:/deps/mwtl. The installed package resolves the same immutable WTL and WIL revisions.

Create a ZIP package

cmake --build build/x64 --config Release --target package

Offline dependencies

cmake -S . -B build/x64 -G "Visual Studio 17 2022" -A x64 \
  -DMWTL_WTL_SOURCE_DIR=C:/deps/wtl \
  -DMWTL_WIL_SOURCE_DIR=C:/deps/wil
