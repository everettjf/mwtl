mwtl::Application

Application 是里程碑 1 的进程入口适配器。它保存 non-owning HINSTANCE，管理 WTL CAppModule、CMessageLoop、主窗口对象和所有失败路径的逆序清理。

完整示例

#include <mwtl/mwtl.h>

class MainWindow final : public mwtl::Window<MainWindow> {
public:
    void BuildUI() { SetTitle(L"Application demo"); }
};

int WINAPI wWinMain(HINSTANCE instance, HINSTANCE, PWSTR, int show) {
    try {
        mwtl::Application app(instance);
        return app.Run<MainWindow>(show);
    } catch (...) {
        return EXIT_FAILURE;
    }
}

生命周期保证

  1. 初始化唯一的 WTL _Module。
  2. 注册栈上的消息循环。
  3. 在栈上构造主窗口 C++ 对象并创建 HWND。
  4. 运行消息循环并返回其退出码。
  5. 所有正常和受控失败路径先移除消息循环，再终止 _Module。
Application 不可复制、不可移动；一次只管理一个活动运行周期。wWinMain 仍应保留最后一道 catch 边界。
