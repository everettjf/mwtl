mwtl::Window<T>

Window 是 WTL CRTP 主顶层窗口基类。它不隐藏 HWND 或消息映射，并在 WTL 实际 WindowProc 外建立 noexcept C++ 异常边界。

原生消息互操作

constexpr UINT kRefresh = WM_APP + 1;

class MainWindow final : public mwtl::Window<MainWindow> {
public:
    void BuildUI() { SetTitle(L"Window demo"); }

    BEGIN_MSG_MAP(MainWindow)
        MESSAGE_HANDLER(WM_LBUTTONDOWN, OnClick)
        MESSAGE_HANDLER(kRefresh, OnRefresh)
        CHAIN_MSG_MAP(mwtl::Window<MainWindow>)
    END_MSG_MAP()

private:
    LRESULT OnClick(UINT, WPARAM, LPARAM, BOOL&) {
        return ::SendMessageW(GetHwnd(), kRefresh, 0, 0);
    }
    LRESULT OnRefresh(UINT, WPARAM, LPARAM, BOOL&) {
        SetTitle(L"Native message received");
        return 0;
    }
};

关键行为

  • BuildUI() 在 WM_CREATE 阶段、HWND 已附着后调用。
  • GetHwnd() 返回 non-owning 原生句柄；IsWindow() 观察实时有效性。
  • 派生消息映射必须通过 CHAIN_MSG_MAP 链回 mwtl/WTL 基类。
  • WM_NCDESTROY 后不再暴露旧 HWND。
  • 创建期异常导致 Create 失败；普通消息异常触发安全关闭；异常不会越过 Win32 ABI。
