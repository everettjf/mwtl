Modern wrappers, native HWNDs

Label, Button, TextBox, CheckBox, RadioButton, GroupBox, ComboBox, ListBox, ProgressBar, and Slider are move-only owners of real system child windows. The gallery executable creates every supported wrapper. DIP bounds, UTF-16 text, command events, and direct GetHwnd() access coexist.

using mwtl::operator""_dip;

void BuildUI() {
    name.Create(*this, {100}, L"Ada",
        {{24.0_dip, 24.0_dip}, {280.0_dip, 32.0_dip}});
    greet.Create(*this, {101}, L"Greet",
        {{320.0_dip, 24.0_dip}, {120.0_dip, 32.0_dip}});
}

void OnCommand(const mwtl::CommandEvent& event) {
    if (event.IsClicked(greet)) {
        SetTitle(L"Hello, " + name.GetText());
    }
}
