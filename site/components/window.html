WindowBase and Window<T>

WindowBase is the concise default: the class name appears once and virtual hooks propagate to Win32 unless overridden. Window<T> remains the advanced CRTP path for compile-time dispatch, custom class traits, and legacy WTL message maps.

Macro-free message interoperability

constexpr UINT kRefresh = WM_APP + 1;

class MainWindow final : public mwtl::WindowBase {
public:
    void BuildUI() override { SetTitle(L"Window demo"); }

    mwtl::EventResult OnLeftButtonDown(const mwtl::MouseEvent&) override {
        ::SendMessageW(GetHwnd(), kRefresh, 0, 0);
        return mwtl::EventResult::Handled();
    }

    mwtl::EventResult OnMessage(const mwtl::WindowMessage& message) override {
        if (message.id == kRefresh) {
            SetTitle(L"Native message received");
            return mwtl::EventResult::Handled();
        }
        return mwtl::EventResult::Propagate();
    }
};

Key behavior

  • BuildUI() runs during WM_CREATE after the HWND is attached.
  • GetHwnd() returns the native handle.
  • EventResult::Propagate() continues default processing.
  • The advanced Window<T> form supports existing WTL maps and void convention handlers.
  • Both paths remain inside the same noexcept WindowProc boundary.
