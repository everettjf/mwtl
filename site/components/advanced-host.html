Advanced native window host

Per-window DPI, configurable HWND creation, wait-aware pumping, safe worker wake-up and optional COM apartment ownership—while native messages remain fully accessible.

DPI + bounds

DpiContext converts explicit DIP geometry and WindowOptions places a client or outer rectangle on the target monitor.

Wait without polling

WaitAwareMessagePump combines Win32 handles, messages and bounded idle work with MsgWaitForMultipleObjectsEx.

Safe wake-up

WindowWakeup is a weak token that becomes invalid before WM_NCDESTROY completes.

Native by design

WTL message maps continue to handle DPI, power, settings, accessibility, input and rendering messages directly.
