Build guide

Build and run

Requirements: Windows 10 version 1809 or newer, Visual Studio 2022 or newer, MSVC, a Windows SDK, the C++ ATL component, CMake 3.21 or newer, and C++20.

x64 Debug

cmake -S . -B build/x64 -G "Visual Studio 17 2022" -A x64 \
  -DMWTL_BUILD_EXAMPLES=ON -DMWTL_BUILD_TESTS=ON
cmake --build build/x64 --config Debug --verbose
ctest --test-dir build/x64 -C Debug --output-on-failure

Run component examples

build\x64\examples\application\Debug\mwtl_application_demo.exe
build\x64\examples\window\Debug\mwtl_window_demo.exe
build\x64\examples\hello\Debug\mwtl_hello.exe

ARM64 build

cmake -S . -B build/arm64 -G "Visual Studio 17 2022" -A ARM64 \
  -DMWTL_BUILD_EXAMPLES=ON -DMWTL_BUILD_TESTS=OFF
cmake --build build/arm64 --config Release --verbose
The ARM64 target requires the MSVC ARM64 compiler, ARM64 ATL, and matching Windows SDK libraries. An x64 host can normally cross-compile these executables but cannot run the ARM64 GUI examples directly.

Offline dependencies

cmake -S . -B build/x64 -G "Visual Studio 17 2022" -A x64 \
  -DMWTL_WTL_SOURCE_DIR=C:/deps/wtl \
  -DMWTL_WIL_SOURCE_DIR=C:/deps/wil
