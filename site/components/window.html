mwtl::Window<T>

Window is the WTL CRTP top-level window base. C++20 requires expressions discover common typed handlers, while HWND access and legacy WTL message maps remain available.

Macro-free message interoperability

constexpr UINT kRefresh = WM_APP + 1;

class MainWindow final : public mwtl::Window<MainWindow> {
public:
    void BuildUI() { SetTitle(L"Window demo"); }

    void OnLeftButtonDown(const mwtl::MouseEvent&) {
        ::SendMessageW(GetHwnd(), kRefresh, 0, 0);
    }

    mwtl::EventResult OnMessage(const mwtl::WindowMessage& message) {
        if (message.id == kRefresh) {
            SetTitle(L"Native message received");
            return mwtl::EventResult::Handled();
        }
        return mwtl::EventResult::Propagate();
    }
};

Key behavior

  • BuildUI() runs during WM_CREATE after the HWND is attached.
  • GetHwnd() returns the native handle.
  • A void convention handler consumes its message; EventResult::Propagate() continues default processing.
  • Existing WTL message maps can still override and chain to the mwtl base.
  • All paths remain inside the same noexcept WindowProc boundary.
