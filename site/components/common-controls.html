Native Windows Control Library

Specialized Common Controls

One populated gallery exercises every specialized family while keeping the HWND, messages, styles, and return values available.

Data and navigation

TreeView, ListView, Header, TabControl, and ComboBoxEx.

Input and information

DateTimePicker, MonthCalendar, HotKey, IpAddress, UpDown, SysLink, Tooltip, and ImageList.

Commands and containers

Toolbar, StatusBar, Rebar, Pager, Animation, TaskDialog, ScrollBar, and Flat Scroll Bar integration.

Read the complete example

The API covers the control families, not every possible Win32 style combination. Advanced native messages remain directly available through GetHwnd().
