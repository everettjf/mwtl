mwtl::Application

Application is the process-entry adapter. It stores a non-owning HINSTANCE and manages the WTL CAppModule, CMessageLoop, main-window object, optional COM apartment, and reverse-order cleanup on every failure path.

Complete example

#include <mwtl/mwtl.h>

class MainWindow final : public mwtl::Window<MainWindow> {
public:
    void BuildUI() { SetTitle(L"Application demo"); }
};

int WINAPI wWinMain(HINSTANCE instance, HINSTANCE, PWSTR, int show) {
    try {
        mwtl::Application app(instance);
        return app.Run<MainWindow>(show);
    } catch (...) {
        return EXIT_FAILURE;
    }
}

Lifetime guarantees

  1. Initialize the single WTL _Module.
  2. Register the stack-owned message loop.
  3. Construct the main-window C++ object on the stack and create its HWND.
  4. Run the message loop and return its exit code.
  5. On normal and controlled failure paths, remove the message loop before terminating _Module.
Application is neither copyable nor movable and manages one active run at a time. Keep a final catch boundary in wWinMain.
