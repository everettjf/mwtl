Quick start

Hello, native window.

最短示例只需要一个 CRTP 窗口类和 Application 入口。

#include <mwtl/mwtl.h>

class MainWindow final : public mwtl::Window<MainWindow> {
public:
    void BuildUI() { SetTitle(L"mwtl hello"); }
};

int WINAPI wWinMain(HINSTANCE instance, HINSTANCE, PWSTR, int show) {
    try {
        return mwtl::Application(instance).Run<MainWindow>(show);
    } catch (...) {
        return EXIT_FAILURE;
    }
}

实际 target：mwtl_hello。最终 EXE 嵌入 Unicode/ComCtl v6 与 Per-Monitor V2 manifest。
